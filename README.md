# KursusKu Prototype

Prototype aplikasi KursusKu menggunakan PHP.

## Fitur

- Landing page KursusKu
- Waktu server
- Kalkulator biaya kursus
- Katalog 6 kursus
- Status kursus Penuh/Tersedia
- Perhitungan sisa kursi
- Format rupiah dan tanggal
- Pengujian fungsi
